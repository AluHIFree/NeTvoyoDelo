NeTvoyoDelo — локальная версия (Python устанавливать НЕ нужно)
================================================================

КАК ЗАПУСТИТЬ
1. Распакуйте архив в любую папку (например, Документы\NeTvoyoDelo-Local).
2. Дважды нажмите START.bat
3. Откроется браузер: http://127.0.0.1:8000
4. Войдите как администратор (см. ниже).

ОСТАНОВКА
- Закройте окно START.bat или запустите STOP.bat

ВХОД ПО УМОЛЧАНИЮ
- Логин:  admin
- Пароль: admin123
Сменить можно в файле .env:
  ADMIN_USERNAME / ADMIN_PASSWORD / ADMIN_EMAIL

НАСТРОЙКИ (.env)
Все параметры рядом с START.bat — почта (SMTP_*), Cloudflare AI
(CLOUDFLARE_*), SMS и т.д. После правок .env перезапустите сервис
(STOP → START).

БЕЗОПАСНОСТЬ
Сервис слушает только 127.0.0.1 (ваш компьютер), из сети недоступен.
База данных: correspondences.db в этой же папке.

ЧИСТАЯ УСТАНОВКА
В сборке только аккаунт администратора, отделы не созданы.
Добавляйте отделы и сотрудников через панель администратора.

ТРЕБОВАНИЯ
Windows 10/11 x64.
