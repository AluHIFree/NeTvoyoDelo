# Changelog

Все значимые изменения проекта фиксируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.1] - 2026-09-18

### Улучшено

- Парсер почты: кэш уже разобранных писем, пакетный IMAP FETCH и параллельный разбор вложений (поиск быстрее без потери качества)
- В **Справке** добавлен раздел «Парсер почты»; README обновлён

## [1.2.0] - 2026-09-18

### Добавлено

- Раздел **Парсер почты**: подключение своего IMAP (Яндекс / Mail.ru / Gmail / произвольный)
- Поиск писем по смыслу с разбором темы, текста и вложений PDF / DOCX / RTF / TXT
- Если точного совпадения нет — показ ближайших вариантов
- Пароль приложения хранится в БД в зашифрованном виде (Fernet от `SECRET_KEY`)

## [1.1.1] - 2026-09-18

### Исправлено

- Пустой `executor_id` в поиске писем больше не вызывает ошибку валидации (OptionalInt)
- Ссылки сохранённых фильтров используют параметр `saved_filter_id`

## [1.1.0] — 2026-09-17

### Добавлено

- Раздел **Обновления** для администратора: проверка новых версий на GitHub
- Безопасная установка обновлений без затрагивания базы данных, `.env` и вложений
- Файл `VERSION` / `app/version.py` для отслеживания локальной версии

### Исправлено

- Портативная сборка больше не включает секреты разработчика в `.env`
- Добавлен `.gitignore` и корневой `.env.example`

## [1.0.0] — 2026-09-17

### Добавлено

- Первая публичная версия системы учёта входящей корреспонденции
- Портативная Windows-сборка с встроенным Python
